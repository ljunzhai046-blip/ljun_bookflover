# 1.C语言的起源

C语言起源于1972年，由丹尼斯·里奇（*Denies Ritch*）和肯·汤普逊（*Ken Thompson*）在实验室里开发UNIX操作系统时所设计。

## 2.选择C语言的理由

### 2.1设计特性

2.1.1 自顶向下
2.1.2 结构化编程（顺序，选择，循环结构）
2.1.3 模块化设计（即把大的复杂的程序拆分成若干功能的小块）特点为：独立性，可复用，易读好维护。

### 2.2高效性

C语言充分利用了计算机的优势，因此C程序相对更紧凑，==运行速度快==。具有微调控能力，可以根据具体情况微调程序以获得最大运行速度或最有效运用内存。

### 2.3 可移植性

可移植性使得C语言可以方便地在不同的操作系统上运行

## 3. C语言的属性

3.1 C语言时高级编程语言，而且是编译型语言。遵循ANSI/ISO发布的C标准。

3.2 使用C语言的七个步骤分别是：1.定义程序的目标，2.设计程序，3.编写代码，4.编译，5运行，6，测试和调试程序，7.维护和修改程序。

## 4.编程机制

4.1 用C语言编写程序时，编写的内容被保存为文本文件以“.c”后缀结尾，被称为==源代码文件==。
4.2 源代码文件通过C语言编辑器翻译成==目标代码文件（.obj）==，属于机器语言但是无法直接执行，因为它缺少了库文件和启动代码，所以是中间代码。需要连接器来将他们链接起来。
4.3 ==链接器==将中间代码和需要的库文件以及启动代码整合成".exe"文件，才是可以被执行的代码。
