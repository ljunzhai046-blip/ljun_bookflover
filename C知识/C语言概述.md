## 1 简单C程序

1.1 简单C程序的结构如下：
		#include <stdio.h>
		  int main(void)
		  {
			   语句     /* 大部分的语句都以分号结尾 
			   return 0;
		  }
1.2  C 语言种常见的6种语句为：1.标号语句，2.复合语句，3.表达式语句，4.选择语句，5.迭代语句，6.跳转语句。他们都由“关键字，标识符，运算符和数据”构成。

## 2 简单程序的构成要素

2.1 指令和头文件：#include <stdio.h> 的作用相当于把stdio.h文件中的所有内容都输入该行所在的位置。
	#include 这行代码是一条C预处理指令（*preprocessor directive*）,通常C编译器会在编译前对源代码做==预处理==
	  stdio.h这样的文件被称为头文件它包含了编程所要用的某些函数，像stdio.h的含义就是标准输入/标准输出的头文件包含了如“printf(),scanf()”这样的函数，供编程使用
2.2 main() 函数：main函数是函数的一种，与其它函数在构造上并无二致，但是程序想要运行，必须得有main()函数，而且C程序一定从main函数开始执行，一个程序只允许有一个main()函数。
完整结构是：
		int main() //"void" 可写可不写
		{
		
	        return 0;
		}
 2.3 注释：C中提供了两种方式，第一种采用一对“/*“ 和 */” 这样的格式，在这两个符号内的内容成为注释。例如：/ *C是一种高级编程语言   * /。只要是在这两个符号之间的都是注释内容，可以跨行，所有要格外注意符号的配对，不然可能会将你的代码，变成注释的内容。
    
第二种方式是使用两个斜杠”//“来加入单行的注释，从”//“后到这行结尾之间的内容为注释内容，例如：// C是一种高级的编程语言

这两种都是注释的方法，注释内容不参与编译，只供开发者或读者阅读。

2.4 花括号，函数体和块：C语言使用花括号标记函数体的开始和技术，函数即是C语言的构造快。花括号可以把函数中的多条语句合并为一个单元或块，其他括号例如中括号“[]”,和括号"()"没有这种功能。

2.5 声明：声明是C语言最重要的特性之一，它把特定标识符与计算机中的特定位置联系起来，并确定了存储在这些位置里的信息类型或数据类型。声明可以如变量声明，函数声明，或其它的实体声明。在如今的C标准中，声明可以在代码的任何地方进行声明，但要保证在你调用这些数据之前声明好。

2.6 数据类型以及命名：C中常用的数据类型粗略分为整数，字符和浮点数。
  命名时，可以用小写字母，大写字母，数字和下划线（_）来命名。==而且名称的第一个字符必须是字母或下划线，不能是数字==。**且不能与关键字相同，也不应与保留标识符相同**（虽然不会报错，但是会是如"printf"这样的保留标识符失去作用）。

2.7 赋值：赋值是C语言的基本操作之一。赋值是把右边的值赋到左边的变量的过程，在赋值计算符“=”右边可以是值或表达式，但左边不能是表达式只能是单一的变量。
