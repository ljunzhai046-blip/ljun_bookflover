
# 简介：

  在C语言中基本数据类型大致分为两大类，即==整数类型==和==浮点类型==。

## 1.整数类型：
  1.1整数类型的关键字：
     *char,short,int,long,long long*,也可以追加使用*unsigned/signed*来设置无符号和有符号的类型，以及_Bool类型（无符号）。
     这里要注意的是，虽然char类型存储的是字符，但是从技术层面看，它也是整数类型。因为它是存储ASCII编码来显示字符，char类型虽然只有一字节，但ASCII编码的范围是0-127，只需7位二进制数就可以表示。所以char类型归根结底存储的还是整数。
     _ Bool类型是逻辑值true/false,返回1/0，原则上只占用一位就够了，本质上也是整数类型。
  1.2整数类型的存储：
     整数类型的数字以二进制形式存储在内存中，一般来说，一个字节有八位，即可表示（-2的8次方~2的8次方-1）这个范围，那么在int占用4个字节的电脑上，它所能够有效存储的数值范围在（-2147483648~2147483647，*第一位存储的是符号*）之间，一旦超过这个数值就会产生上溢，或者下溢（即在这个范围内循环）超过特别多的也可能会返回一些特殊的提示。
     无符号的类型因为第一位不需要存储符号可以表示一个更大的正整数。
  1.3整数的表示方式：
     在C中，整数可以用十进制，八进制，十六进制来表示同一个值。二进制是机器内部存储时采用的数据格式，编码中并不支持。
     在使用十进制时，没有特殊的前后缀，用==0前缀表示八进制==，用0x/0X前缀表示十六进制数。
     特殊的，l/L后缀表示该类型时long类型，整数浮点数都适用。
## 2.浮点数类型：
  2.1浮点数类型的关键字：
     float,double,long double。有些实现还支持了复数类型和虚数类型，需通过_Complex和_Imaginary关键字和以上三种关键字组合来表示负数和虚数。
     另外需要注意的是，有些编译环境下，long doule的语法可能是编辑正确的，但是编译器却无法识别该类，导致数据输出错误，这种情况下直接换用double就行。
  2.2浮点数类型的存储：
     与整数类型简单的使用二进制来进行存储不同，浮点数是分成小数部分和指数部分来表示的。在计算机内部也是用二进制，但是用二进制和2的幂来存储。因为这个存储特性，浮点类型在相同存储大小的条件下可以表示比整数类型更多，更大的数。
     另外C标准规定，float类型必须至少能表示6位有效数字，且取值范围至少是（10E-37~10+37）前一项表明float类型必须能表示33.3333333的前六位数字，后面表示它可以存储一个很大的数。通常，系统存储一个浮点数需要32位的空间，其中8位用来表示符号和指数的值，剩下24位用于表示分指数部分（也叫尾数或有效数，其中一位也用来表示非指数部分的符号。）
     double类型和float类型的最小取值范围相同，但至少必循能够表示10位有效数字。long double最小与double相同。
 2.3浮点数的表示方式：
     一般浮点数可由整数部分加小数点来表示，也可以运用科学计数法来表示，例如：1E41，表示1乘上10的41次方。也可以用16进制数和2的幂来表示，例如：0xa.1fp10,其中p10是2的10次方。

## 3.转义字符：

  在C中，直接表示一个字符的方法是把该字符用单引号括起来，如：‘q’,'A'等。
  一般‘\’号加一个特定的字符，可表示转义序列，例如‘\n’表示换行符，执行到它后会跳到新的一行。
  另外，在八进制或十六进制数前加上一个‘\’,如‘\007’，也可表示一个ASCII字符。


## 4.不同类型对应的转换说明符



|     类型      |      转换说明      |
| :---------: | :------------: |
|    char     |       %c       |
|    short    |       %d       |
|     int     |       %d       |
|    long     |      %ld       |
|    八进制整数    | %d/%o(数值大用%ld) |
|   十六进制整数    | %d/%x(数值大用%ld) |
|    float    |       %f       |
|   double    |     %f/%lf     |
| long double |      %lf       |
|   科学技术小数    | %e/%f(数值大用%lf) |
|   十六进制小数    | %a/%f(数值大用%lf) |

## 5.可移植类型

如果想在不同的电脑上获得一块大小固定的同类型的空间，可以使用stdint.h和inttypes.h头文件。
stdint.h包含了：
精确宽度整数类型，如：int32_t
最小宽度类型，如:int_least8_t
最快最小宽度类型，如：int_fast8_t

inttypes.h 则支持了这些类型的显示
