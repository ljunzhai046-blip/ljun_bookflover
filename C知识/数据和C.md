
# 简介：

  在C语言中基本数据类型大致分为两大类，即==整数类型==和==浮点类型==。

## 1.整数类型：
  1.1整数类型的关键字：
     *char,short,int,long,long long*,也可以追加使用*unsigned/signed*来设置无符号和有符号的类型，以及_Bool类型（无符号）。
     这里要注意的是，虽然char类型存储的是字符，但是从技术层面看，它也是整数类型。因为它是存储ASCII编码来显示字符，char类型虽然只有一字节，但ASCII编码的范围是0-127，只需7位二进制数就可以表示。所以char类型归根结底存储的还是整数。
     _ Bool类型是逻辑值true/false,返回1/0，原则上只占用一位就够了，本质上也是整数类型。
