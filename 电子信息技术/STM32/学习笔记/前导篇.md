#电子信息 #stm32 

# 单片机简介

1.单片机是什么：*Single-Chip Microcomputer*,单片微型计算机，是一种集成电路芯片。
{(类比电脑)
   cpu     ——> cpu
   SARM ——> 内存
   Flash   ——> 硬盘
   外设    ——> 主板
}

2.单片机的特点：体积小，功耗低，集成度高，使用方便，扩展灵活。

3.单片机的发展：

  （从时间来看）MCS-51 ——>MCS-96 ——>ARM,RISC-V

  （从产品需求来看）SCM单片形态——> MCU完善控制——>SoC软硬件协同设计。

4.发展趋势：
     cpu:高主频/64位/双CPU/流水线
     存储器：MB级/内部ROM——>FLASH化/程序加密
     提高IO功能
     提升集成度
     品种多样化
5.CISC/RISC：（复杂/精简指令集）
     CISC：x86,Intel公司
     RISC: ARM;MIPS;RISC-V(开源)，ST公司


# Cortex-M 简介

单片机的内核常使用ARM架构，ARM的内核又分了很多种，例如Cortex-A,Cortex-B,Cortex-C;
stm32多使用Cortex-M的内核架构。

1.ARM公司：只负责内核设计和IP授权。不参与芯片设计，芯片设计交与合作伙伴，合作伙伴找厂商批量生产后卖给商家
2.常见的STM32内核有Cortex-M3/4/7，性能根据数字的大小提升。
