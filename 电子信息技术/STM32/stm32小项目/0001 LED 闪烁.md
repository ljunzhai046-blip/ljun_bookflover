## 2 接线部分

**第五步：硬件接线**

本实验需要以下硬件：

    1. STM32F103C8T6 最小系统板

    2. ST-Link V2 下载器

    3. LED 灯 1 个

    4. 面包板 1 块

    5. 杜邦线若干（母对母 4 根用于 ST-Link 连接，公对公 / 母对公用于 LED 电路）

**一、ST-Link 与 STM32 的接线**

ST-Link 通过 SWD（串行调试）接口与 STM32 连接，需要接 4 根线：

ST-Link 的 3.3V  ---->  STM32 的 3.3V（或 3V3）

ST-Link 的 SWCLK ---->  STM32 的 SWCLK（或 DCLK）

ST-Link 的 SWDIO ---->  STM32 的 SWDIO（或 DIO / SWIO）

ST-Link 的 GND   ---->  STM32 的 GND（或

**重要注意事项：**

    1. ST-Link 两排针脚的定义不同！必须接在远离缺口的那一排针脚上。

    2. 不同批次的 ST-Link，引脚排序可能不同。请严格按照 ST-Link 外壳上标注的引脚标号接线，不能只根据引脚位置来判断。

    3. 不同批次的 STM32 最小系统板，引脚标号缩写可能不同，以下同一行的标号均表示同一个引脚：

3.3V  =  3.3  =  3V3

SWCLK =  DCLK

SWDIO =  DIO  =  SWIO

GND   =  G

**二、LED 灯的接线**

LED 灯有两个引脚，长脚为正极（阳极），短脚为负极（阴极）。接线方式如下：

LED 正极（长脚）  ----> STM32 的 GND（或面包板 GND 轨）

LED 负极（短脚）---->   你在cubemx设置的gpio口（图示的为pa4）

**三、接线检查清单**

    [ ] ST-Link 连接到远离缺口的那排针脚

    [ ] 3.3V 对 3.3V，SWCLK 对 SWCLK，SWDIO 对 SWDIO，GND 对 GND

    [ ] LED 正极（长脚）连接到 GND

    [ ] LED 负极（短脚）通过电阻连接到 PA4

    [ ] 确认没有将 5V 连接到 3.3V 引脚（会烧毁芯片）
