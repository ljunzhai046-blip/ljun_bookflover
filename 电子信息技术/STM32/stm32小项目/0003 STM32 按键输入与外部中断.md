
**引入：为什么需要按键**

前两次实验中，单片机一直在“自说自话”：第一次按固定节奏闪灯，第二次通过串口和电脑聊天。但有一

个问题：如果我想在程序运行过程中告诉单片机“现在切换个模式”“现在停一下”，怎么办？总不能每次都

改代码重新烧录。

按键就是单片机的“触觉”。有了它，人可以直接和单片机交互：按一下切换档位、按一下启停设备。这是

几乎所有电子产品的标配——遥控器、洗衣机、电梯按钮，背后都是按键输入。

本次实验我们让单片机学会“感觉”：按一下按键，LED 翻转，同时串口打印一条消息。

==🟡**第一步：轻量原理 —— 三句话看懂按键与中断**==

一、上拉电阻是什么

按键的接法很简单：一脚接 PA0，另一脚接 GND。问题是：按键没按下时，PA0 处于悬空状态（谁也不接），电平高低不定，像一根“天线”一样乱飘，单片机可能误判。

上拉电阻就是一根把 PA0 轻轻“拽”到高电平的橡皮筋：按键没按时，PA0 稳定在高电平；按键按下时，PA0直接接通 GND，变成确定的低电平。

STM32 内部自带上拉电阻，CubeMX 里勾选 Pull-up 即可，不需要外接任何元件。

记结论：本次按键“没按 = 高电平，按下 = 低电平”。

**二、外部中断（EXTI）是什么**

EXTI（External Interrupt，外部中断）是 STM32 里专门监视引脚电平变化的功能模块。


配置好之后，当 PA0 的电平从“高变低”的瞬间（也就是按键按下的瞬间），硬件会自动暂停主程序，转去

执行一段我们写好的函数（回调函数），执行完再回来接着干原来的活。

电平“高变低”叫下降沿，“低变高”叫上升沿。我们的按键按下是下降沿，所以本次选下降沿触发。

**三、按键抖动是什么（了解即可）**

机械按键内部是金属弹片，按下和松开的瞬间，触点会快速通断好几次——几毫秒内电平像“弹跳”一样反复抖动，而不是干净利落的一次变化。

后果：按一下，单片机可能以为按了五六下。解决办法叫消抖：检测到变化后，短时间（比如 50ms）内的重复变化直接忽略。本次两个实验分别用两种消抖方法，下面会讲。

二、配置上拉与触发方式

1. 左侧栏找到 System Core → GPIO，点击进入，在引脚列表中点击 PA0 那一行。

2. 下方出现 PA0 的详细配置，设置两项：

• GPIO mode：External Interrupt Mode with Falling edge trigger detection（下降沿触发，即按键“按下”

的瞬间触发）

• GPIO Pull-up/Pull-down：Pull-up（开启内部上拉，按键没按时稳定在高电平）

三、开启 EXTI 中断（NVIC）

1. 左侧栏 System Core → NVIC，在表格中勾选 EXTI line0 interrupt 的 Enabled（PA0 对应的中断线就

是 EXTI0）。

这一步和第二次开启串口中断是同样的操作，含义也一样：“有按键了再叫我”。
