**第一章 PWM基础概念**

**1.1 什么是PWM？**

PWM全称**脉冲宽度调制（Pulse Width Modulation）**，是一种通过调节数字方波信号的高电平持续时间，来等效模拟出不同电压值的数字调制技术。

单片机输出的信号只有两种状态：高电平（3.3V/5V）、低电平（0V），无法直接输出0~5V之间的模拟电压。而PWM通过快速切换高低电平，利用“占空比等效电压”的原理，实现**数字信号模拟化输出**，是单片机最核心的外设功能之一。

**1.2 PWM核心三大参数**

想要读懂和配置PWM，必须掌握三个核心参数，三者决定了PWM信号的所有特性：

**（1）周期（Period）**

一个完整高电平+低电平的持续时间，单位为秒（s）、毫秒（ms）或微秒（μs）。

**PWM频率**：周期的倒数（f=1/T），表示1秒内完整波形的个数，单位Hz。频率越高，输出的等效电压越平稳。

**（2）高电平时间（Ton）**

一个PWM周期内，输出高电平的持续时间，也叫脉冲宽度。

**（3）占空比（Duty Cycle）**

高电平时间占整个PWM周期的百分比，计算公式：**占空比 = Ton / T × 100%**

占空比是PWM最核心的调节参数，直接决定等效输出电压：

• 0%占空比：全程低电平，等效电压0V，设备不工作

• 50%占空比：高低电平时间相等，等效电压为电源电压的1/2

• 100%占空比：全程高电平，等效电压为满电压，设备满负荷工作

**1.3 PWM核心应用场景**

基于电压等效原理，PWM广泛应用于各类嵌入式场景：

• 灯光控制：LED亮度无级调光、RGB彩灯调色

• 电机控制：直流电机调速、舵机角度控制、步进电机细分驱动

• 电源控制：开关电源、电池充电稳压

• 发声设备：蜂鸣器、喇叭音调调节

**第二章 单片机PWM实现原理**

**2.1 单片机PWM生成两种方式**

**（1）软件模拟PWM（通用所有单片机）**

无需硬件外设支持，通过**定时器中断+延时函数**，手动控制IO口高低电平翻转，实现PWM波形输出。

**优点**：任意IO口均可实现，适配所有普通单片机，灵活度高；**缺点**：占用CPU资源，频率精度低，高频率下波形不稳定。

**（2）硬件PWM（主流单片机标配）**

利用单片机内置的**定时器/PWM专用外设**，硬件自动生成波形，无需CPU全程干预。配置完成后，外设独立输出PWM信号，CPU可执行其他任务。

**优点**：精度高、频率稳定、不占用CPU资源、可实现高频PWM；**缺点**：仅指定专用IO口支持，通用性稍弱。

**新手建议**：入门先学软件PWM理解原理，进阶使用硬件PWM做实际项目。

**2.2 硬件PWM核心工作逻辑**

单片机硬件PWM基于**定时器计数比较模式**工作，核心流程如下：

1. 配置定时器定时周期，确定PWM总周期；

2. 设置比较阈值（匹配值），确定高电平持续时间；

3. 定时器从0开始自动递增计数；

4. 计数值 < 匹配值：IO口输出高电平；

5. 计数值 ≥ 匹配值：IO口翻转低电平；

6. 计数溢出归零，重新循环，持续输出稳定PWM波形。

**第九章 学习总结**

1. PWM核心本质：**通过调节脉冲宽度，实现数字信号模拟输出**，核心参数为周期、频率、占空比；

2. 软件PWM适配所有单片机，适合原理学习；硬件PWM精度高、省资源，适合项目开发；

3. 所有单片机PWM配置逻辑通用：**配置定时器周期→设置比较值→开启输出→动态调节占空比**；

4. PWM是嵌入式控制的核心技术，熟练掌握可快速实现灯光、电机、电源等绝大多数模拟控制场景。
